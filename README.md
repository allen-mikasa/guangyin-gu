# 光阴蛊

考公自习计时桌面应用。光阴滚滚，寸阴是竞。

Electron 31 + 原生 HTML/CSS/JS，无前端框架、无外部音频文件（环境声由 Web Audio 实时合成），全部数据只存本机。

## 一、安装与运行

两种方式任选：

**A. 直接下载**：到 [Releases](../../releases) 下载最新一版的 `光阴蛊-安装包-x.y.z.exe`（NSIS 安装版）或 `光阴蛊-便携版-x.y.z.exe`（绿色单文件，不写注册表）。

**B. 从源码构建**：

```powershell
npm install
npm start            # 开发运行
npm test             # 跑回归测试（194 项）
npm run build:win    # 打包 Windows 安装包与便携版 → dist/
```

> Windows 首次运行若弹出 SmartScreen 提示，选择「更多信息 → 仍要运行」即可（应用未做商业代码签名，属正常现象）。

## 二、功能

### 刻漏（计时页）

- **正计时**：不限时长，记录真实学习时长，圆环以一小时为一圈；
- **倒计时**：内置 1/3/5/10/25/30/45/60/90 分钟快捷时长，支持自定义到秒；
- **专注**：番茄钟式循环，可设专注 / 短休 / 长休时长与「几轮一长休」（默认 25/5/15、每 4 轮长休）。专注段自动计入学习科目，休息段自动记为「休息」，段段留痕；
- **科目 / 事项**：内置修习科目（资料分析、言语理解、判断推理、数量关系、常识判断、政治理论、申论）与凡尘诸事（休息、用餐、运动、杂务、睡眠），均可自定义增删改；
- **光圈随进度变色**：翠绿起步，每五分之一依次转为赤红 → 银白 → 金黄 → 亮紫，档内平滑过渡（可在设置里关闭，关闭后回到金玉渐变、休息为青玉）；
- **声境**：海浪、细雨、溪涧、晚风、篝火、白噪音六种环境声，可多选混音、各自调音量；
- 到点自动鸣钟三响并弹系统通知；计时中每 15 秒落一次心跳，异常退出后已计时长不丢，暂停态可跨重启恢复。

### 浮窗置顶

- 一键把主窗缩成贴边的置顶小窗，只留表盘与按钮；
- 计时中可进一步缩为屏幕角落的**胶囊**（时长、科目一目了然）；
- 胶囊**按住任意空白即可拖动**（由系统接管，不会出现"越推越往回"），点科目名回主窗、点 `✕` 退出置顶；
- 窗口与胶囊位置会记住，重启后回到原处；拔掉副屏后若跑到屏幕外会自动拉回可见区域；
- 隐藏窗口后可由**托盘图标**或 `Ctrl+Alt+G` 召回，`Ctrl+Alt+C` 收起/唤出胶囊。

### 长河（统计页）

- 时段切换：日 / 周 / 月 / 年 / 总计，可前后翻页回到任意历史区间；
- 五张统计卡（区间修习、区间凡尘、卷宗条目、日均修习、专注圆满）；
- 「光阴长河」堆叠柱状图：上段修习（金）、下段凡尘（青玉），**任意层级都可点击下钻**；
- 各科修习分布排行；
- 「长河星图」：日/周视图看近二十周、月/年/总计看近十二月，每列 7 格（周一→周日），**点格子可跳到那一天**。

### 卷宗（记录页）

- 全部计时按日分组，可按「修习 / 诸事」筛选；
- **按事项名称搜索**：即时过滤、显示命中条数、`Esc` 或 `✕` 清空，与场景筛选叠加；
- 每条记录含日期、起止时辰、科目、模式、轮次、时长、状态（圆满 / 中辍）；跨零点的记录按天拆开显示并标注「跨夜」；一轮计时分了多段（暂停续计）会标注 `1/2`、`2/2`；
- **改名时可同时改归属**，把事项在「修习 / 诸事」之间移动；
- 支持删除单条、清空全部（均有二次确认），一键导出 CSV。

### 极往（自选统计页）

- 把出现过的科目/事项做成可点选的标签，可只选一项，也可多选任意几项；
- 支持全选 / 清空 / 只选修习 / 只选诸事快捷操作；
- 范围可选近七日 / 近三十日 / 近一年 / 全部；
- 概览卡（所选事项数、区间合计、修习占比、日均）；
- 「岁月走势」堆叠柱状图，按范围自动切换粒度（按天 / 按周 / 按月）；
- 「所占份额」逐项列出总时长与占比条；
- 统计口径与长河一致：时长按**真实计时片段与所选区间求交**，跨零点、多片段都正确分摊。

### 设置

顶栏「设置」里可开关：计时结束后自动隐藏窗口、计时中自动缩为胶囊、光圈随进度变色、窗口始终置顶。

## 三、数据存放在哪

所有记录仅保存在本机：

```
%APPDATA%\光阴蛊\guangyin-records.json
```

复制该文件即可备份；重装 / 更换电脑时放回同一路径即可恢复全部记录。安装版与便携版共用此数据文件。窗口位置、设置项另存于同目录下的 `guangyin-window.json` 与浏览器本地存储中。

## 四、项目结构

```
main.js              主进程入口（窗口、托盘、单实例、全局快捷键）
pip.js               浮窗置顶 / 胶囊状态机、多屏定位、位置持久化
window-state.js      窗口与胶囊位置持久化（含可见性校验）
backend.js           记录存储（JSON 原子写入）、IPC、到点兜底、系统通知
preload.js           主窗 contextBridge 桥接
capsule-preload.js   胶囊 contextBridge 桥接
src/
  index.html         三个主页面 + 极往 + 两个弹窗
  styles.css         墨金古风主题
  renderer.js        全部渲染与统计逻辑
  audio.js           Web Audio 环境声合成
  capsule.html       胶囊外观（系统拖动 + 点击展开）
  capsule-renderer.js
tests/               回归测试（Node 直跑真实函数体）
scripts/build.js     打包入口（规避 ELECTRON_RUN_AS_NODE 环境坑）
scripts/verify-installed.js  从已安装的 app.asar 反向核验功能是否真的进包
```

## 五、回归测试

```powershell
npm test
```

194 项断言，全部在 Node 中直接执行 `src/renderer.js` 的真实函数体（伪造 DOM 与 Electron），覆盖时间桶分摊、跨夜拆分、日均口径、自动结算重入、星图结构、搜索与归类、极往统计、浮窗状态机与拖拽契约等。部分用例带**反向验证**开关（如 `LEGACY_BUG=1`），可确认测试确实抓得住对应缺陷而不是"永远绿"。

其中浮窗相关的用例会注入一个**忠实还原 Electron 行为**的假 electron 模块（例如 `setVisibleOnAllWorkspaces()` 返回 `undefined` 而非 Promise），用于拦截只在真实运行时才暴露的兼容性问题。
